# Java-Projects   
Hotel Room Booking Management System using Java

Developed a Hotel Room Booking Management System using Java and OOP concepts. The project allows users to manage Luxury and Non-Luxury rooms, check room availability, book and cancel rooms, view customer booking details, and calculate bills based on room type and stay duration.

Technologies: Java, OOP, Classes, Objects, Arrays, Constructors and Methods.
